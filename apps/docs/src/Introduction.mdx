# HaltH Design System

The HaltH Design System is the shared component library used across HaltH products. See **Guidelines** for the design concepts and rules (when to use what), and **Design System** for every colour, type style and component on one page.

- **`@halth/design-system`:** React components built on HeroUI v3 (Button, Card, …)
- **`@halth/design-system-tokens`:** Colours, radius, fonts, Tailwind v4 / HeroUI v3 themes and Tailwind v3 / NativeWind presets

## Install

```bash
# .npmrc
@halth:registry=https://npm.pkg.github.com

npm install @halth/design-system @halth/design-system-tokens
```

## Tailwind v4 + HeroUI v3

```css
/* globals.css */
@import 'tailwindcss';
@import '@heroui/styles';
@import '@halth/design-system-tokens/heroui.css';
@source '../node_modules/@halth/design-system/dist';
```

## Usage

```tsx
import { Button } from '@halth/design-system/button';

<Button variant="outline" onPress={save}>Save</Button>
```
