# HaltH Design System

Every HaltH foundation and component on one page. Colours come straight from `@halth/tokens` and the components below are their live stories, so this page updates as soon as the library does.

## Colours

### Semantic

Use these class names in app code (`bg-primary`, `bg-secondary`, `text-muted-foreground`). In HeroUI apps, `bg-accent` is the brand colour and `text-muted` is secondary text.

<SemanticColors />

### Palette

The full scales behind the semantic colours, e.g. `bg-primary-50` or `text-sun-600`. New colours go in `packages/tokens/src/colors.ts`.

<ColorPalette>
  {scales.map(([name, shades]) => (
    <ColorItem
      key={name}
      title={name}
      subtitle={`${name}-*`}
      colors={Object.fromEntries(
        Object.entries(shades).map(([shade, hex]) => [shade === 'DEFAULT' ? name : shade, hex])
      )}
    />
  ))}
  <ColorItem title="Brand" subtitle="bg-cream, bg-forestBg, …" colors={brandColors} />
</ColorPalette>
